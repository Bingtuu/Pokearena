# 抓包操作指南（task 001 · 路线 A 验证）

目标：抓到"宝可梦卡牌会员"小程序的**卡牌列表**和**卡牌详情**两类 HTTPS 请求，交给 AI 分析接口可行性。
你只需要完成下面"用户操作"部分（约 15 分钟），其余分析由 AI 完成。

## 原理一句话

mitmproxy 在本机开一个代理（127.0.0.1:8080），让 PC 微信的流量经过它；安装它的 CA 证书后，它就能看到 HTTPS 明文，并把全部请求录制成 flows 文件。

## 用户操作（共 5 步）

### 第 1 步：启动代理

在项目根目录的 Git Bash 里运行：

```bash
tools/capture/.venv/Scripts/mitmdump.exe --listen-port 8080 \
  --set confdir=tools/capture/.mitmproxy \
  -w "data/raw/capture/pokemon-$(date +%Y%m%d-%H%M).flows"
```

看到 `HTTP(S) proxy listening at *:8080` 即正常。**这个窗口保持开着**。

### 第 2 步：安装 CA 证书（首次一次性）

1. 先用资源管理器打开 `tools/capture/.mitmproxy/`（第 1 步运行后自动生成），双击 `mitmproxy-ca-cert.cer`；
2. 点"安装证书" → 当前用户 → "将所有的证书都放入下列存储" → 选"**受信任的根证书颁发机构**" → 完成；
3. （安全提示弹窗点"是"——这是你自己本机生成的证书，抓完第 5 步会删掉。）

### 第 3 步：设置系统代理

Windows 设置 → 网络和 Internet → 代理 → 手动设置代理：
- 地址 `127.0.0.1`，端口 `8080`，保存。
- ⚠️ "请勿对以下地址使用代理"里如有内容，追加 `;pokemon.cn` 相关域名不要填进去——微信域名必须走代理。

### 第 4 步：操作小程序（关键）

1. **完全退出 PC 微信**（托盘图标右键退出），再重新打开（让它读到新代理设置）；
2. 打开"宝可梦卡牌会员"小程序，进入卡查/卡牌搜索功能；
3. 做这些动作，每个动作停 2~3 秒：
   - 按系列浏览卡牌列表，翻 2~3 页；
   - 用关键词搜索一次（如"喵喵"）；
   - 点开 **2 张卡的详情页**：一张普通卡 + 一张机制复杂的卡（如"火箭队的超梦ex"或太晶卡），详情页里各 Tab 都点一下；
4. 回到 Git Bash，按 `Ctrl+C` 停止 mitmdump，然后**告诉我"抓完了"**。

### 第 5 步：清理（AI 分析完后做，可暂缓）

- 系统代理：设置里关掉"使用代理服务器"；
- 删证书：`certmgr.msc` → 受信任的根证书颁发机构 → 找到 `mitmproxy` 删除。

## 常见问题

| 现象 | 处理 |
|---|---|
| 小程序提示网络异常/一直转圈 | 大概率是对方有证书固定（pinning）→ 直接告诉我现象，这本身就是"路线 A 不可行"的证据 |
| flows 文件只有微信域名，没有卡牌数据 | 小程序可能从缓存读取 → 退出小程序重进，或换没看过的系列浏览 |
| 微信提示代理不可达 | 确认第 1 步窗口还开着、端口是 8080 |
