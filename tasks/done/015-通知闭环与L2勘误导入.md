## 目标
1. **通知（FR-5.5）**：本地桌面通知（必选，零新依赖——Windows PowerShell toast / macOS osascript / Linux notify-send）+ webhook（可选，httpx POST JSON）。接 L0/L1 的 `on_event` 钩子，只对重要事件触发（增量/阻断/提案/新公告），unchanged 不打扰。通知失败不中断管线。
2. **闭环**：`ptcgdb monitor proposals` 列出待审提案（status/snapshot_id/diff 摘要）；`legal-apply` 成功后回写提案文件 `status: applied` + applied_at——提案生命周期 pending_review/needs_manual → applied 可追溯。
3. **L2 勘误导入（FR-5.3）**：`config/errata/*.yml` 人工维护 → `import_errata` upsert 入 errata 表（card_id 不存在记 warning 跳过，不中断）；CLI `ptcgdb legal-errata`。

## 设计
- `ptcgdb/monitor/notify.py`：`Notifier(desktop, webhook_url, *, runner, poster)`（runner/poster 注入便于 mock）；`notify(title, message) -> list[str]`（返回成功渠道）；`make_event_handler(notifier)` → on_event 回调，事件→文案映射
- `ptcgdb/monitor/proposals.py`：`list_proposals(dir)`（解析 YAML 摘要）、`mark_proposal_applied(path, snapshot_id)`
- `ptcgdb/legal/errata.py`：`ErrataSeed`（pydantic）+ `import_errata(db_path, config_dir)` upsert 幂等
- CLI：`monitor proposals`；`legal-errata`；`monitor l0/l1` 加 `--notify/--no-notify`、`--webhook`
- `config/errata/README.md` 说明 YAML 格式（不放假数据）
