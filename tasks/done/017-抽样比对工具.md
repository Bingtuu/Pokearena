## 目标
A2/A3 需要与官方小程序卡面人工比对（小程序无 API，D1 已否决）——本 task 交付**工具与清单**，人工比对另约协作 session：
- **A2**：固定种子随机抽 100 张 active 卡（可复现），生成逐字段比对清单（卡名/编号/赛制标记/罕贵度/HP/属性/特性/招式/弱点/抵抗/撤退/text_raw）+ 小程序查卡指引。
- **A3**：特殊卡机制字段**自动一致性校验**（全量特殊卡，非抽样）+ 抽 50 张出卡面核对清单。

## A3 自动校验项（DB 内逻辑闭环，PRD A3 口径）
1. prize_cards 规则：rule_box_type ∈ {ex, gx} → 2；{tag_team_gx, v_union} → 3
2. ACE SPEC：is_ace_spec → deck_limit == 1 且为训练家卡
3. V-UNION：union_position 非空 ⟺ 出现于 union_part_of 关系；每组 4 部件齐全
4. owner：owner 非空 ⟺ name_full 以 owner 词表前缀开头（5 组训练家宝可梦）
5. 进化：evolves_from_text 非空 → evolves_from_id 已解析且指向卡存在
不符项如实记录、标记需人工裁决，不猜测性修数据。
