## 设计决定（已落 PRD v1.8）

- **范围约束（用户定）**：只入能映射到简中环境的卡组——CN 天然对应；EN/JP
  按映射率分档 mapping_status（full ≥95% / partial / unmapped），统计仅消费 full。
- **统计范围（用户定，硬约束）**：使用率/胜率统计仅 宝可梦/支援者/竞技场
  （stat_scope 派生过滤位）；能量/物品/宝可梦道具不进统计。粒度 = name_group。
- **保真**：deck_cards 全量 60 张落库（含能量），validate_deck 真值校验（task 026）
  与统计复用同一事实源；映射不上的卡 card_id 置空 + raw_name 保真，不猜。
- **胜率语义诚实声明**：mik 无逐局对阵（swiss 仅进行中）→ 代理指标 = 名次加权
  使用率 + top-cut 转化率；逐局 matchup 仅 Limitless pairings（EN）后置。
- **隐私最小化**：player_ref 只存官方选手编号 pinCode，不存昵称。
