## 调研结论（设计依据）

- **EN 映射**：raw 已有英文桥字段（`setCodeEn/cardIndexEn/nameEn`），直接提取为主路径。
- **JP 映射**：TCGdex 卡级数据日文 100% 覆盖，且同一 card ID 多语言共构（`SV8-001` 在 en/ja 端点同 ID）——EN↔JP 桥在 TCGdex 内部平凡可得，**不爬 pokemon-card.com**（官方 JP 卡查仅作抽样权威核对）。
- **繁中方向取消**：不做 asia.pokemon-card.com 采集；`name_zh_tw` 字段保留预留不填充（字段只加不删）。
- **校验源新增**：TCGdex 已收录全部简中系列壳（set_id 与本库一致）但卡级 0%——可用于**系列级交叉校验**（系列名 + cardsNum 对账）；卡级字段校验仍无第二结构化源（小程序无 API、52poke 维基非结构化），维持同源自验 + A2/A3 人工比对口径。TCGdex zh-cn 实装进风险登记册持续跟踪。
- **mik.moe 赛事数据库**（2023 广州大师赛以来官方积分赛卡组）列为 task 026 真实卡组校验数据源。
