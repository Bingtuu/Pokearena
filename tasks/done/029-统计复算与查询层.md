## 目标

让下游用户**像写 SQL 一样**基于本库自行复算 FR-9.4 三指标（WUR / WR / WWS）：
权重输入全量落库、公式以 canonical SQL 单一事实源公开、CLI/SDK/导出三处同口径，
官方公布的任何统计数字都可由第三方用库存事实原样重放（FR-9.6 可复算性契约）。

## 实现段口径注记（2026-08-02，设计细化）

- **w̃ 归一化范围**：w̃_d = w_d / Σw 的归一化在 **mapping_status='full' 出战条目范围内**
  进行（与 v_stat_deck_cards 过滤一致）——partial/unmapped 卡组完全隔离于统计，
  其存在不稀释 full 卡组的份额（"统计仅消费 full"的严格语义）。
- **w_d 取值**：points > 0 时取 points，否则（NULL 或 0，如瑞士轮预赛场次）回退 1/rank。
- **WR-B topcut 判定**：rank ≤ tournaments.topcut_slots；topcut_slots 为 NULL 的赛事
  不参与 B 层（meta 回显 excluded 数）。
- **mirror 参数**：当前 schema 无 pairings 表（Limitless 未接入），参数接受并回显
  口径标签，实际不剔除（诚实声明，task 028 接入后生效）。
- **权重输入缺失**：tier_coef 或 participant_count 为 NULL 的赛事静态权重为 NULL，
  自然被 SUM 跳过（不计入任何指标分子分母）。

## 设计决定（已落 PRD v1.10）

- **事实完整性**：tournaments 加 `topcut_slots` / `tier_coef`（物化自词表，SQL 消费方
  免读 yml）；deck_appearances 挂 `record_wins/losses/ties`（A 层，可空；task 027
  真实数据订正后 record 属出战条目而非内容实体）；主键口径
  `{source}:{源侧id}` 防跨源碰撞。
- **派生非真相**：统计只以视图/查询存在；物化视图 `v_stat_deck_cards`（四表联查 +
  范围过滤 + group_key 预联）与 `v_tournament_weights`（静态权重件）随迁移落库，
  视图不含业务公式——公式只在 `ptcgdb/stats/sql/*.sql`。
- **canonical SQL**：参数化（`:as_of` / `:date_from` / `:date_to` / `:scope` …），
  CLI、SDK、schema.md 附录共用同一文件；已实测 SQLite 3.50 具备
  log10 / pow / julianday / 窗口函数，三指标可纯 SQL 表达。
- **口径版本化**：meta 记录 `name_group_rules_hash` / `tournament_tiers_hash`
  （词表 SHA-256 前 12 位）并入 manifest；一切统计输出 meta 回显 as_of/窗口/scope/
  division/口径标签/词表 hash。
- **CLI**：`stats` 升级为子命令组（裸 `ptcgdb stats` 兼容旧对账 = overview）：
  `usage / winrate / wws / card <名>` + 公共参数（--as-of/--from/--to/--window-days/
  --scope/--tier/--division/--min-n/--format table|json|csv）；
  新增 `ptcgdb query "<SELECT ...>"` 只读 ad-hoc SQL（mode=ro，仅 SELECT/WITH，
  拒写操作与 ATTACH，默认 LIMIT 500）。默认口径 division=master、排除 is_qual/is_team。
- **SDK**（FR-8 追加）：`db.stats_usage/stats_winrate/stats_wws/stats_card`
  → frozen `CardStat`（group_key/display_name/value/n/basis/layer/low_confidence）。
- **导出追加**（FR-7 只加不删）：tournaments/decks/deck_cards 三个 JSONL
  （deck_cards 附 group_key/stat_scope 冗余列免联表），manifest.counts 加三项，
  schema.md 附 canonical SQL 全文与复算示例。
- **数据质量门**：deck_cards count 合计 = 60（异常赛制登记豁免）；(deck_id, card_id,
  raw_name) 唯一；mapping_status 阈值固化 full ≥95%；导出前 foreign_key_check +
  integrity_check 通过。计算全链 float64，表格展示 4 位、JSON/CSV 全精度。

### 真实数据驱动的两处修正（相对最初设计）

1. **wws.sql 的 WUR 因子恒用全口径赛事范围**：否则 WWS ≠ WUR × WR_adj，破坏
   FR-9.6 可复算契约；B 层子范围为空（topcut_slots 全 NULL）时诚实返回空结果
   （不加 WHERE 会产 NULL 值行使 CardStat 校验崩）。
2. **黄金集 T6（topcut=NULL）锁定 meta n_tournaments 口径**：B 层统计
   n_tournaments 不计 topcut 未知赛事。
